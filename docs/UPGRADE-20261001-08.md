# Petclinic 0.8 视觉升级 · 2026-10-01

用户明确继续 Petclinic，因为之前页面不够绚丽。以已上线的 `0.7.0-ci-82` 为基线，不接续 DCP/DataOps。

## 设计与范围

采用 Electric Garden 视觉方向：钴蓝、荧光柠檬黄和珊瑚色；真实摄影配合有机环形轮廓、装饰贴纸和光环。首页增加重叠浮层统计、三色业务入口及珊瑚色行动区。导航与业务页统一蓝色标题横幅、淡蓝底色、圆角面板及表单焦点状态。

沿用本地字体和原来的原创摄影，不新增远端字体、图片或脚本。新增 CSS 负责视觉层，没有新增常驻 JavaScript。入场与悬停动效均可通过 prefers-reduced-motion 关闭。装饰元素不参与读屏和键盘导航；真实统计继续从数据库读取。

保留原有搜索、筛选、分页、宠物详情、就诊提交和历史回看。不更改 Java 模型、数据库结构、数据、探针、调度或基础设施。原有未跟踪 `ops/` 保留。
